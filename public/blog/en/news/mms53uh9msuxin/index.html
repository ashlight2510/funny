How to Use GitHub Integration in VSCode: A Beginner's Guide

Hello! Are there any of you who find it difficult to use GitHub with VSCode? I also struggled a lot at first, so I thought I would summarize how to integrate GitHub with VSCode. I'll explain it in a way that beginners can easily follow!

Setting Up a GitHub Account

First, you need to create a GitHub account

To use GitHub, you need an account first. If you don't have one yet, go to the GitHub homepage and sign up. Don't forget to set up your profile after signing up! Personally, I think it's good to add one or two projects to your profile. It makes you look more trustworthy when collaborating with others.

Connecting Your GitHub Account in VSCode

Now, let's open VSCode and connect your GitHub account. Click the "Extensions" button in the sidebar and search for "GitHub Pull Requests and Issues" to install it. After the installation is complete, click the "Manage" icon in the bottom left corner, and you'll see the "Sign in to GitHub" option. Click it and enter your account information to complete the connection!

Creating a Git Repository

Creating a New Repository

If you've created a project to work on in VSCode, it's time to create a Git repository. Open the terminal and enter the following command.

git init

This will create a Git repository in the current folder. Then, add files with git add . and create your first commit with git commit -m "Initial commit". Personally, I think it's important to write good commit messages. They are much more useful when checking the change history later!

Pushing the Repository to GitHub

After creating the repository, don't forget to push it to GitHub! Create a new repository on GitHub and enter the following commands in VSCode.

git remote add origin [repository URL]
git push -u origin master

This will upload your local work to GitHub. It can be nerve-wracking at first, but you'll get used to it quickly as you continue!

Utilizing GitHub Integration Features in VSCode

Creating a Pull Request

Now let's make full use of VSCode's GitHub integration features. After committing the files you've worked on, click the "…" button in the "Source Control" panel and select "Create Pull Request." Thanks to this feature, you can create a Pull Request directly from VSCode, which is really convenient!

Managing Issues

Finally, let's manage issues. Open the "GitHub" panel in VSCode and click "Issues" to check existing issues or create new ones. I think it makes communication with team members much smoother. Organizing tasks through issues and checking progress is much more efficient.

Conclusion

This is how to integrate and use VSCode with GitHub. It may feel difficult at first, but with a little practice, you can definitely do it! If you have any questions, please leave a comment. I hope you can practice right after reading this article!
