Improving Coding Speed with Cursor Manipulation in VSCode

When coding, you often wonder how to manipulate the cursor effectively, right? Especially when moving to a desired part in long code, you might hesitate between using the mouse or keyboard shortcuts. So today, I've organized ways to manipulate the cursor in VSCode. Utilizing these will definitely speed up your coding!

Utilizing Cursor Movement Shortcuts

Learning Basic Shortcuts

The first thing to know is the basic shortcuts for moving the cursor. For example, the ↑, ↓, ←, → keys allow you to move the cursor one line or one character at a time. But that's not all. By pressing Ctrl + ↑ or Ctrl + ↓, you can move the cursor up or down one page. Using this, I found that I no longer needed to move the mouse unnecessarily, saving a lot of time.

Selecting Multiple Lines

Now let's learn how to select multiple lines. By holding down the Shift key and pressing the arrow keys, you can easily select multiple lines. I found this very convenient as it allowed me to modify several lines at once. It was particularly useful when I needed to change multiple instances of the same format in the code.

Utilizing the Multi-Cursor Feature

Editing Simultaneously with Multi-Cursors

Next is the multi-cursor feature. By holding down Alt while clicking, you can place cursors in multiple locations at once. This is a truly innovative feature. For instance, when I wanted to change variable names in several places at once, I could modify them all without clicking one by one. Personally, this feature has significantly reduced the time I spend editing code.

Creating Multi-Cursors with Shortcuts

Additionally, by pressing Ctrl + Alt + ↑ or Ctrl + Alt + ↓, you can add new cursors above or below the current cursor position. I found this incredibly useful for repetitive tasks. It was especially effective when I needed to insert the same content across multiple lines. I regret not knowing about this feature sooner!

Remembering Cursor Positions

Adding Bookmarks to Frequently Visited Locations

Finally, there's a way to remember cursor positions. VSCode has many extensions that allow you to add bookmarks to specific locations. One of the extensions I've used is called Bookmarks. Once installed, you can save the locations of frequently visited code snippets as bookmarks and easily navigate to them. Before this feature, I struggled to find them by scrolling down every time, but now I can move with just a few clicks, which is really convenient.

Conclusion

I've summarized various ways to manipulate the cursor in VSCode. By utilizing simple shortcuts and the multi-cursor feature, your coding speed will definitely improve. From my experience, these methods have been incredibly useful. If you have any questions, feel free to leave a comment! I recommend starting with these tips!
