Using Code Blocks in Notion Like VSCode: Tips and Tricks

Do you know how useful the combination of Notion and VSCode can be when working with code? Especially using code blocks in Notion allows you to manage projects and document them simultaneously, which is really convenient. However, utilizing code blocks in Notion isn't as straightforward as it seems, so I had some concerns. Therefore, I've organized this information. I'll share a few tips and tricks on how to use code blocks in Notion conveniently, just like in VSCode!

1. Creating a Code Block

How to Add a Code Block

Creating a code block in Notion is simpler than you might think. Just create a new block and type “/code,” and the code block option will appear. Selecting this will allow you to start entering your code.

From my experience, this method gives a bit of the feel of writing code in VSCode. Of course, it’s not perfect like VSCode, but it’s really useful for basic documentation. You can set the language within the code block, supporting various languages like Python and JavaScript, so you can configure it according to the language you are using.

Importance of Language Selection

This part was important. When I first entered code without selecting a language, it just looked like plain text. So, specifying the language enhances syntax highlighting and improves readability, making it look much better. I recommend trying to select the language you are using!

2. Editing Within the Code Block

Freedom to Edit

Notion's code blocks don’t offer as many editing features as VSCode, but basic editing is possible. After entering the code, if there are errors, it’s easy to fix them. I’ve modified the code several times, and being able to make real-time edits was really convenient.

Here’s a tip! After selecting the code block, you can easily copy the entire code by clicking the ‘Copy’ button in the top menu. You can copy it as you would in VSCode, but this method might make your work a bit easier.

3. Useful Features for Collaboration

Sharing with Team Members

Notion is a really useful tool for collaboration with team members. After creating a code block, sharing it with teammates makes code reviews easy. In a previous team project, we utilized code blocks in Notion to review each other's code, and using the comment feature for feedback was very efficient.

When working with team members, it’s important to use code blocks to clearly share each other's code. Especially since you can add explanations or notes about the code, it makes it easier to understand when revisiting later. This aspect greatly aids collaboration.

4. Documentation Strategy Through Code Blocks

Importance of Documentation

By utilizing Notion's code blocks, you can document not only the code but also related documentation. While working on a project, I organized documents alongside the code, making it easier to revisit later and increasing my understanding of the project.

An important point here is to add explanations below the code block. This way, you create a document that is easy to understand for others or for yourself later. Personally, I found this method of documentation very beneficial.

Conclusion

We explored how to use code blocks in Notion like in VSCode. Utilizing code blocks makes documentation and collaboration much smoother, so I hope you give it a try! If you have any questions, feel free to leave a comment. I think starting with this would be great!
