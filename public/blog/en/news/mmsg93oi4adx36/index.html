Organizing Notes with Obsidian and Using Them in VSCode

March 16, 2026

How to Organize Notes with Obsidian and Utilize Them in VSCode

Have you ever felt overwhelmed about how to start organizing your notes? Especially as a developer, having the right tools to organize your thoughts is crucial. Recently, I’ve been using Obsidian to organize my notes and figured out how to leverage that content in VSCode.

What is Obsidian?

A New Paradigm for Note-Taking

Obsidian is a markdown-based note-taking tool. When I first tried it, I thought, "Ah, this is really the tool for me!" Unlike other note apps that simply store text, it allows you to easily organize the relationships between notes through links and tags. This was a significant advantage for me personally. For example, if I connect notes related to a project, I can easily find them whenever I need.

Creating My Own Knowledge Network

One of the biggest attractions of Obsidian is that it allows you to create your own knowledge network. You can visually see the notes connected through links, which helps you understand how much you know about a particular topic. This aspect was really important for me. I was unsure about what to write, but organizing it this way made it much easier.

Integration with VSCode

Moving from Obsidian to VSCode

After organizing notes in Obsidian, there are several ways to utilize them in VSCode. First, you can open the markdown files from Obsidian in VSCode. Since the notes you write in Obsidian are saved as .md files, you can directly open them in VSCode. I found it useful when organizing content related to code. You can refer to necessary notes while coding in VSCode.

Using the Markdown Preview Extension in VSCode

However, if you want to see a preview while working on markdown files in VSCode, I recommend installing the "Markdown Preview" extension. This allows you to see the output of your markdown file in real-time. I found it really convenient to write notes while simultaneously checking the results.

Enhancing Connectivity Between Notes

Utilizing Tags and Links

When organizing notes in Obsidian, it’s important to effectively use tags and links. By organizing topics with tags, you can easily find similar notes. Additionally, visually showing the relationships between notes through links greatly helps in understanding complex topics. Personally, I found this method to be very efficient.

Creating My Own Templates

Lastly, creating your own templates can make note-taking much easier in the future. For example, if you create templates for the necessary information or checklists for each project, you won’t have to write in the same format every time. Doing this has significantly reduced my note-taking time and allowed me to focus more.

Conclusion

In conclusion, organizing notes with Obsidian and utilizing them in VSCode is beneficial in many ways. Through this combination, I was able to create my own knowledge network and work on development tasks more efficiently. If you have any questions, please leave them in the comments! I think starting with this would be great.
