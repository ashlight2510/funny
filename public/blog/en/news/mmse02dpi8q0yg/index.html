How to Fix "Permission Denied" Error When Running npm install

March 16, 2026

How to Resolve "Permission Denied" Error When Running npm install

It's quite frustrating when you try to run npm install at the start of a project and encounter a "permission denied" error. I felt lost when I first faced this error, not knowing what went wrong. So, I've put together some solutions to help you out!

1. Global Installation Permission Issues

Understanding Permission Issues

The most common reason for a "permission denied" error when executing npm install is insufficient permissions needed to install global packages. This means you don't have access to system files or folders, which is particularly a problem for Mac or Linux users.

How to Resolve It?

In this case, you can try using the sudo command. For example, you can enter the following:

sudo npm install -g <package-name>

I've tried this method, and it's simple and effective. However, this approach can be a bit risky, so it's best to use it only when necessary.

2. Resetting npm Permissions

Changing Permission Settings

Personally, I recommend resetting the permissions for npm. This method may be a bit cumbersome, but it can help prevent errors in the future.

Here's How

First, change the default path for npm. Enter the following commands:

mkdir ~/.npm-global
npm config set prefix '~/.npm-global'

Then, add ~/.npm-global/bin to your PATH. You can do this by adding the following line to your ~/.bash_profile or ~/.bashrc file:

export PATH=~/.npm-global/bin:$PATH

Finally, to apply these changes, restart your terminal or enter the following command:

source ~/.bash_profile

Doing this cleaned up my environment and eliminated the permission issues.

3. Reinstalling Node.js and npm

Considering Reinstallation

If the problem still isn't resolved, completely reinstalling Node.js and npm can be a good option. This can reduce the chances of permission issues during the installation process.

How to Do It?

First, uninstall the currently installed Node.js and npm. Remove them completely from your system, and then download and install the latest version from the official website. This method can be a bit tedious, but it often serves as a solution.

4. Managing with nvm

Using nvm

Lastly, I recommend using Node Version Manager (nvm). With nvm, you can manage multiple versions of Node.js, which significantly reduces permission issues.

Installation Method

Installing nvm is straightforward. You can install it with the following command:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash

After installation, you can install your desired version of Node.js:

nvm install node

This way, you can use it conveniently without permission issues.

Conclusion

Ultimately, the "permission denied" error often stems from permission issues. You should be able to resolve it easily with the methods mentioned above. If you have any questions, feel free to leave a comment! I hope you can quickly resolve this error by referring to this article when it occurs!
