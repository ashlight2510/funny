Writing Development Notes with Obsidian: Analyzing Differences with VSCode

Writing Development Notes with Obsidian: An Analysis of Differences with VSCode

When developing, many people often struggle with how to organize their notes effectively. Especially when you want to jot down code snippets or project ideas, it can feel overwhelming to choose the best tool. So this time, I’ve summarized the differences between Obsidian and VSCode. Both tools have their own strengths, but let’s take a look at which tool is more useful in different situations!

Features of Obsidian

Note Linking and Graph View

Obsidian's link-based note-taking is incredibly powerful. You can connect the notes you write together, making it usable like a wiki. For example, if you write a note about a specific project and link related notes within it, you can easily find them later. This method is particularly useful when dealing with complex concepts or large projects. It felt a bit awkward at first, but later I found this feature to be fantastic!

There’s also a graph view feature. You can see at a glance how many notes you’ve written and what topics you are focusing on, making it easy to understand your areas of concentration. This is really useful. It even motivates you to think, “Should I organize these notes again?”

Features of VSCode

Code-Centric Development Environment

VSCode is, of course, an optimized IDE for writing code. Thanks to various plugins and extensions, it provides all the necessary features while developing. For instance, writing code snippets and adding comments is really convenient. If you have frequently used code snippets, you can easily save and retrieve them in VSCode. So, when writing code, using VSCode is really comfortable.

However, I feel it has some limitations when it comes to note-taking. Since it focuses on code, it’s less suitable for freely recording or organizing ideas compared to Obsidian. Therefore, I separate my development-related notes in Obsidian and write code in VSCode.

Integrated Use of Obsidian and VSCode

Creating My Own Workflow

The way I use both tools together is quite simple. When writing code in VSCode, I jot down any necessary ideas or notes in Obsidian. This way, I can gather all information related to the code in one place, making it much easier to refer back to later. Working this way has made me feel more productive.

Additionally, by utilizing Obsidian's template feature to create frequently used note formats in advance, I can reduce the effort of writing them repeatedly. These small tips add up to make a significant difference.

Conclusion

In conclusion, Obsidian and VSCode each have different advantages. I recommend using Obsidian for development notes and VSCode for writing code. This way, you can organize information in the way you want and stay focused on development. If you have any questions, please leave a comment! Or while reading this article, it might be a good idea to organize your own note-taking method.
