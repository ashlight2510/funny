Managing GitHub Repositories with VSCode: A Beginner's Tutorial

Recently, I started developing and wanted to try using GitHub and VSCode, but I found myself at a loss about how to get started. Being a beginner, it wasn't easy to follow along step by step. So, I decided to organize my thoughts. I'll briefly introduce how to manage GitHub repositories using VSCode!

1. Connecting VSCode to GitHub

Installing VSCode and Setting Up Git

First, you need to have VSCode installed. The installation is straightforward, so you can download it from the official website and install it. You'll also need Git. If Git is not installed, you can download it here and install it. After installation, you need to do some basic setup by entering the following commands in the command prompt or terminal.

git config --global user.name "Your Name"
git config --global user.email "Your Email"

This way, Git will recognize your information. Personally, I felt it was important to enter my name and email correctly. Since commit history is recorded, it helps to easily check what work I have done later.

Connecting Your GitHub Account in VSCode

Now, let's connect your GitHub account in VSCode. Open VSCode and click on the source control icon in the left sidebar (usually the third icon). You should see a "Login" button. Click it to log in to GitHub, and VSCode will be connected to GitHub. During this process, you might be asked for simple authentication, so it's good to have your login information ready.

2. Creating a New Repository

Creating a Repository

Now, let's create a new repository. In VSCode, select "File" -> "New Folder" to create a project folder. Then, right-click inside the folder and select "Open Integrated Terminal." In the terminal, enter the following command to initialize the repository.

git init

This will create an empty repository. Next, you can add your files and commit them using the following commands.

git add .
git commit -m "First commit"

From my experience, writing good commit messages is really important. It helps a lot when checking the work history later!

3. Connecting the Repository Remotely

Uploading the Repository to GitHub

To upload the repository to GitHub, you first need to create a new repository on GitHub. Log in to GitHub, click the "New" button, enter the repository name, and click "Create repository." Then, copy the URL of the created repository.

Return to the VSCode terminal and enter the following commands.

git remote add origin <repository URL>
git push -u origin master

This will connect your local repository with the remote repository. At first, I found it quite confusing, but after trying it several times, I quickly got used to it.

4. Managing Changes

Modifying Files and Committing

Now it's time to modify files. After editing your code or documents, you can enter git add . and git commit -m "Modification details" in the terminal. Then, entering git push will reflect the changes on GitHub.

I find this part really convenient. Since you can do everything in VSCode, the workflow becomes much smoother. Initially, I made many mistakes, but after repeating the process, I can now do it naturally.

Conclusion

This is how we explored managing repositories using VSCode and GitHub. I believe beginners can definitely follow along. If you have any questions, feel free to leave a comment! And I recommend starting with this: create your own repository and practice committing. You'll understand it much better!
