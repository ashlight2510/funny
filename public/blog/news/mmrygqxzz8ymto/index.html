Node.js 프로젝트에서 자주 발생하는 오류와 그 해결방법

Node.js로 프로젝트를 진행하다 보면, 여러 가지 오류에 부딪히게 되잖아. 특히 초보자일수록 "이게 왜 안 되지?"라는 고민을 자주 하게 되는 것 같아. 그래서 내가 자주 발생하는 오류와 그 해결 방법을 정리해 봤어. 이 글을 통해 여러분이 조금이나마 도움이 되길 바라!

1. 모듈을 찾을 수 없다는 오류 (Cannot find module)

실수로 모듈을 잊고 설치했을 때

첫 번째로 자주 발생하는 오류는 "Cannot find module 'xxx'"야. 이게 발생하면 정말 멘붕이 오더라. 내가 처음 Node.js를 시작했을 때, 필요한 모듈을 설치하는 걸 깜빡해서 이 오류에 자주 시달렸어.

해결 방법

이럴 땐 간단해. 필요한 모듈을 다시 설치해주면 돼. 예를 들어, npm install <모듈명>을 실행하면 되지. 또, 모듈이 설치된 위치가 맞는지도 확인해보는 게 좋더라.

개인적으로는, 자주 사용하는 모듈은 프로젝트의 package.json에 추가해두면 나중에 설치할 때 편하더라. 이걸 통해 기본적인 의존성을 관리할 수 있어!

2. 포트 충돌 오류 (EADDRINUSE)

이미 사용 중인 포트를 요청할 때

두 번째로 많이 겪는 오류는 포트 충돌이야. "EADDRINUSE"라는 메시지를 보면, 이 포트가 이미 다른 프로세스에서 사용 중이라는 뜻이야. 처음에는 당황했었는데, 이 부분에서 주의할 점을 알게 됐어.

해결 방법

가장 쉬운 방법은 사용 중인 포트를 확인하고, 그 포트를 비활성화하는 거야. lsof -i :<포트번호> 명령어로 어떤 프로세스가 포트를 사용 중인지 확인할 수 있어. 이걸로 프로세스를 종료해주면 해결돼.

내가 개인적으로는 포트 번호를 자주 바꾸는 편이야. 개발할 때는 3000번, 4000번 등 여러 포트를 사용해 보니 충돌이 줄어들더라.

3. 비동기 코드에서의 오류 (Unhandled Promise Rejection)

비동기 처리를 할 때

세 번째 오류는 비동기 처리를 하다가 발생하는 "Unhandled Promise Rejection"이야. 비동기 코드는 너무 편리하지만, 잘못 쓰면 이런 오류가 발생하더라. 처음에는 "왜 갑자기 오류가 나지?" 하면서 황당했어.

해결 방법

이 오류를 해결하려면, 항상 try...catch 문을 사용해서 예외 처리를 해주면 좋아. 예를 들어, async 함수 내에서 await를 사용할 때는 반드시 예외 처리를 해줘야 해.

이 부분이 중요하다고 느낀 게, 오류가 발생했을 때 무시하면 나중에 더 큰 문제로 이어질 수 있더라고. 그래서 항상 예외 처리를 해주려고 노력하고 있어.

마무리

Node.js에서 자주 발생하는 오류는 정말 다양해. 하지만 이러한 오류를 해결하는 방법을 알고 있으면, 개발하는 데 큰 도움이 될 거야. 내가 정리한 내용을 참고해서, 다음엔 이런 오류에 부딪히더라도 당황하지 않길 바라!
