VSCode로 GitHub 리포지토리 관리하기: 초보자를 위한 튜토리얼

최근에 개발을 시작하면서 GitHub과 VSCode를 활용해 보려고 했는데, 막상 해 보려니 어떻게 해야 할지 막막했어. 특히 초보자다 보니, 하나하나 따라 하는 게 쉽지 않더라고. 그래서 이걸 정리해 봤어. VSCode로 GitHub 리포지토리를 관리하는 방법을 간단하게 소개할게!

1. VSCode와 GitHub 연결하기

VSCode 설치와 Git 설정하기

먼저, VSCode가 설치되어 있어야 해. 설치는 간단하니까, 공식 웹사이트에서 다운로드받고 설치하면 돼. 그리고 Git도 필요해. Git이 설치되어 있지 않다면 여기에서 다운로드해서 설치하면 좋아. 설치 후에는 기본적인 설정을 해줘야 하는데, 명령 프롬프트나 터미널에 다음 명령어를 입력해 보렴.

git config --global user.name "이름"
git config --global user.email "이메일"

이렇게 하면 Git이 내 정보를 인식하게 돼. 개인적으로는 이름과 이메일을 제대로 입력하는 게 중요하다고 느꼈어. 나중에 커밋 이력이 남기 때문에, 내가 어떤 작업을 했는지 쉽게 확인할 수 있거든.

VSCode에서 GitHub 계정 연결하기

이제 VSCode에서 GitHub 계정을 연결해 볼 거야. VSCode를 열고, 왼쪽 사이드바의 소스 제어 아이콘(보통 세 번째 아이콘)을 클릭해. 그럼 "로그인" 버튼이 보일 거야. 클릭해서 GitHub에 로그인하면 VSCode와 GitHub이 연결돼. 이 과정에서 간단하게 인증을 요구할 수 있으니, 로그인 정보를 잘 준비해 두면 좋아.

2. 새로운 리포지토리 만들기

리포지토리 생성하기

이제 새로운 리포지토리를 만들어 볼 거야. VSCode에서 "파일" -> "새 폴더"를 선택해서 프로젝트 폴더를 만들어. 그런 다음, 폴더 안에서 오른쪽 클릭을 하고 "내장 터미널 열기"를 선택해. 터미널에서 다음 명령어를 입력해서 리포지토리를 초기화해 보면 돼.

git init

이렇게 하면 빈 리포지토리가 만들어져. 그 다음, 내 파일을 추가하고 커밋을 하면 되는데, 이때는 다음 명령어를 사용해.

git add .
git commit -m "첫 커밋"

내가 해 보니, 커밋 메시지를 잘 작성하는 게 정말 중요하더라. 나중에 작업 이력을 확인할 때 도움이 많이 돼!

3. 리포지토리 원격으로 연결하기

GitHub에 리포지토리 업로드하기

리포지토리를 GitHub에 올리려면 먼저 GitHub에서 새로운 리포지토리를 생성해야 해. GitHub에 로그인하고 "New" 버튼을 눌러서 리포지토리 이름을 적고 "Create repository"를 클릭해. 그런 다음, 생성한 리포지토리의 URL을 복사해.

VSCode 터미널로 돌아와서 아래 명령어를 입력해.

git remote add origin <리포지토리 URL>
git push -u origin master

이렇게 하면 로컬 리포지토리와 원격 리포지토리가 연결돼. 처음에는 많이 헷갈렸는데, 여러 번 해 보니 금방 익숙해지더라고.

4. 변경 사항 관리하기

파일 수정 및 커밋하기

이제 파일을 수정해볼 차례야. 코드나 문서를 수정한 후에는 다시 터미널에서 git add .과 git commit -m "수정 내용"을 입력하면 돼. 그 후 git push를 입력하면 변경 사항이 GitHub에 반영되지.

이 부분이 정말 편리한 것 같아. VSCode에서 모든 걸 할 수 있으니까, 작업 흐름이 한층 더 매끄러워지더라고. 처음에는 실수도 많았지만, 반복하다 보니 이제는 자연스럽게 할 수 있게 됐어.

마무리

이렇게 VSCode와 GitHub을 이용해 리포지토리를 관리하는 방법을 살펴봤어. 초보자도 충분히 따라 할 수 있을 거라고 생각해. 궁금한 점은 댓글로 남겨 줘! 그리고 이거부터 해 보면 좋겠어. 직접 리포지토리를 만들어보고, 커밋해 보면서 실습해 보는 거야. 그러면 훨씬 더 이해가 잘 될 거야!
