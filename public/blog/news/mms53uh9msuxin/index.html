VSCode에서 GitHub와의 통합 사용법: 초보자를 위한 가이드

안녕하세요! 혹시 GitHub와 VSCode를 함께 사용하는 게 어렵다고 느끼시는 분들 계신가요? 저도 처음엔 헷갈려서 한참을 고민했었거든요. 그래서 오늘은 VSCode에서 GitHub와 통합해서 사용하는 방법을 정리해 봤어. 초보자도 쉽게 따라할 수 있도록 설명할게!

GitHub 계정 설정하기

먼저, GitHub 계정을 만들어야 해

GitHub를 사용하려면 먼저 계정이 필요해. 아직 계정이 없다면 GitHub 홈페이지에 가서 회원가입을 해 보세요. 가입 후, 프로필을 설정하는 것도 잊지 마! 개인적으로는 프로필에 한두 개의 프로젝트를 추가해 두는 게 좋더라. 다른 사람들과의 협업 시 더 신뢰감 있게 보여지니까.

VSCode에서 GitHub 계정 연결하기

이제 VSCode를 열고, GitHub 계정을 연결해 보자. VSCode의 사이드바에서 "확장" 버튼을 클릭하고, "GitHub Pull Requests and Issues"를 검색해 설치해. 설치가 끝난 후, 왼쪽 아래 코너의 "관리" 아이콘을 클릭하면 "GitHub에 로그인" 옵션이 나올 거야. 클릭해서 계정 정보를 입력하면 연결이 완료돼!

Git 리포지토리 만들기

새로운 리포지토리 생성하기

VSCode에서 작업할 프로젝트를 만들었다면, 이제 Git 리포지토리를 생성해야 해. 터미널을 열고 아래 명령어를 입력해 보세요.

git init

이렇게 하면 현재 폴더에 Git 리포지토리가 생성돼. 그리고 git add .로 파일을 추가하고, git commit -m "초기 커밋"으로 처음 커밋을 만들어줘. 개인적으로는 커밋 메시지를 잘 작성하는 것이 중요하다고 생각해. 나중에 변경 내역을 확인할 때 훨씬 유용하거든!

GitHub에 리포지토리 푸시하기

리포지토리를 만든 후, GitHub에 푸시하는 과정도 잊지 마! GitHub에 새 리포지토리를 생성하고, VSCode에서 아래 명령어를 입력해 보세요.

git remote add origin [리포지토리 URL]
git push -u origin master

이렇게 하면 로컬에서 작업한 내용을 GitHub에 업로드할 수 있어. 처음에는 긴장되지만, 계속 하다 보면 금방 익숙해질 거야.

VSCode에서 GitHub 연동 기능 활용하기

Pull Request 만들기

이제 본격적으로 VSCode의 GitHub 통합 기능을 활용해 보자. 작업이 끝난 파일을 커밋한 후, "Source Control" 패널에서 "…" 버튼을 클릭하고 "Create Pull Request"를 선택해. 이 기능 덕분에 VSCode에서 바로 Pull Request를 만들 수 있어서 정말 편해!

이슈 관리하기

마지막으로 이슈 관리도 해 보자. VSCode에서 "GitHub" 패널을 열고 "Issues"를 클릭하면, 기존의 이슈를 확인하거나 새로운 이슈를 생성할 수 있어. 내가 봤을 땐 팀원들과의 소통이 더욱 원활해지는 것 같더라. 이슈를 통해 할 일을 정리하고, 진행 상황을 체크하면 훨씬 효율적이야.

마무리

이렇게 VSCode와 GitHub을 연동해서 사용하는 방법을 정리해 봤어. 처음에는 어렵게 느껴질 수 있지만, 조금만 연습하면 충분히 할 수 있어! 궁금한 점은 댓글로 남겨 주세요. 이 글을 읽고 나서 바로 실습해 보면 좋겠어!
