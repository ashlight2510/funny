Node.js에서 발생하는 주요 오류와 해결 방법 정리

Node.js를 사용하다 보면 다양한 오류를 마주하게 되지? 특히, 처음 시작할 때는 뭘 잘못했는지 모르겠는 경우가 많아. 이런 오류들은 정말 머리를 아프게 하더라. 그래서 내가 경험한 주요 오류와 그 해결 방법을 정리해 봤어. 이 글이 너에게 도움이 되길 바라!

1. 모듈을 찾을 수 없다는 오류 (Cannot find module)

문제 설명

아마 이 오류를 한 번쯤은 경험해 봤을 거야. Cannot find module 'x'라는 메시지를 보면서 "왜 이렇게 안 되는 거지?" 하고 고민했을 텐데, 이 오류는 주로 설치한 모듈이 없거나 경로가 잘못되었을 때 발생해.

해결 방법

이런 경우에는 먼저 모듈이 제대로 설치되었는지 확인해 보자. npm install 명령어로 재설치를 해 보면 돼. 예를 들어, npm install express처럼 말이지. 그리고 import할 때 경로를 잘 확인하는 게 중요해. 경로가 틀리면 당연히 모듈을 찾을 수 없으니까. 내가 이걸 체크해 보니, 경로의 대소문자도 신경 써야 하더라!

2. 포트 충돌 오류 (Port already in use)

문제 설명

서버를 실행하려고 하면 "Port already in use"라는 오류가 뜨는 경우가 있어. 이럴 땐 "아, 이 포트를 이미 다른 프로그램이 쓰고 있구나" 하고 이해할 수 있어.

해결 방법

이 오류를 해결하려면 먼저 어떤 프로세스가 포트를 사용 중인지 확인해야 해. lsof -i :포트번호 명령어를 사용하면 해당 포트를 사용 중인 프로세스를 볼 수 있어. 그런 다음, 프로세스를 종료하거나 다른 포트를 사용하면 문제가 해결되더라. 나는 이걸 처음에 몰라서 한참 고생했었어. 포트를 바꾸니까 모든 게 잘 되더라.

3. 비동기 처리 오류 (Unhandled Promise Rejection)

문제 설명

비동기 작업을 할 때, Promise가 실패하면 "Unhandled Promise Rejection"이라는 오류가 발생할 수 있어. 이 오류는 코드가 예외를 처리하지 못할 때 나오는 거지.

해결 방법

이런 경우에는 항상 .catch()를 사용해서 에러를 처리해 주는 게 좋아. 이렇게 해 보면 코드가 더 안정적이게 돼. 예를 들어, 아래와 같이 작성할 수 있어:

asyncFunction()
  .then(result => {
    console.log(result);
  })
  .catch(error => {
    console.error('Error:', error);
  });

내가 이 방법을 적용해 보니, 에러가 발생해도 프로그램이 중단되지 않아서 훨씬 좋았어.

4. 메모리 부족 오류 (JavaScript heap out of memory)

문제 설명

대용량 데이터를 처리할 때 "JavaScript heap out of memory"라는 오류가 발생할 수 있어. 이 오류는 Node.js의 메모리 제한을 초과했을 때 생기지.

해결 방법

이럴 땐 Node.js의 메모리 크기를 늘려주면 돼. 서버를 실행할 때 아래와 같이 메모리 한계를 설정해 줄 수 있어:

node --max-old-space-size=4096 app.js

이렇게 해 보니, 메모리 부족 문제를 해결할 수 있었어. 개인적으로는 이 방법이 정말 유용하더라.

마무리

Node.js에서 발생하는 주요 오류와 그 해결 방법을 정리해 봤어. 오류를 해결하는 데 도움이 되었으면 좋겠어. 언제나 코드에서 오류가 발생할 수 있으니, 너무 걱정하지 말고 차근차근 해결해 나가면 돼. 궁금한 점은 댓글로 남겨 줘!
