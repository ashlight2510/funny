VSCode에서 Markdown 문서 작성 및 관리하기

Markdown 문서 작성이 필요할 때, 어떤 툴을 사용할지 고민해 본 적 있지? 나도 한때 여러 가지 툴을 고민했었는데, 결국 VSCode로 결정했어. 이 글에서는 VSCode에서 Markdown 문서를 쉽게 작성하고 관리하는 방법을 정리해 볼게.

Markdown이 뭐길래?

Markdown은 텍스트 기반의 마크업 언어로, 간단한 문법으로 문서를 작성할 수 있는 툴이야. 블로그 포스트, 문서화, 노트 작성 등 다양한 곳에서 활용되는데, 특히 가독성이 좋고 간편해서 많은 사람들이 선호해. 내가 처음 Markdown을 접했을 때, 이게 이렇게 간단하고 유용할 줄 몰랐어. 그래서 VSCode에서 Markdown을 쓰면 어떤 장점이 있는지 알아보자!

VSCode 설치하고 Markdown 확장하기

먼저, VSCode를 설치해야 해. 이미 설치했다면, Markdown 관련 확장을 추가해 보자. 'Markdown All in One' 확장은 내가 가장 좋아하는 거야. 이걸 설치하면 문법 하이라이팅, 미리보기, 자동 완성 기능이 추가돼서 정말 편리하더라. 설치는 간단해! VSCode의 확장 탭(사이드바에서 네모난 아이콘 클릭)에서 'Markdown All in One'을 검색하고 클릭 후 설치하면 돼.

내가 이 확장을 사용해 보니, 문서 작성 속도가 확실히 빨라졌어. 문법 오류를 쉽게 잡아주고, 실시간으로 미리 보기를 해 주니까 정말 좋았어. Markdown 문서 작성이 한결 수월해졌지.

Markdown 문서 작성하기

이제 Markdown 문서를 작성해 보자! 새 파일을 만들고 확장자를 .md로 설정하면 돼. 기본적인 문법은 간단해. 제목은 #, ##, ###로 설정하고, 리스트는 - 또는 *로 만들 수 있어. 예를 들어, 

# 제목
## 소제목
- 항목 1
- 항목 2

이런 식으로 작성하면 돼. 내가 처음 Markdown을 배웠을 때, 이 문법이 너무 간단해서 오히려 재미있더라. 그리고 VSCode의 '미리보기' 기능을 활용하면 작성한 내용을 바로 확인할 수 있으니, 문서 작성이 훨씬 더 직관적이야.

문서 관리하기

Markdown 문서를 작성한 후에는 관리하는 것도 중요해. VSCode에서는 여러 파일을 한꺼번에 관리할 수 있으니, 잘 정리해 두면 좋아. 파일을 폴더별로 나누고, 필요한 문서에 링크를 걸어 주면 나중에 찾기도 쉬워. 예를 들어, 특정 주제에 대한 문서를 작성할 때는 관련 문서와 연결해 두면 좋겠지?

내가 여러 가지 문서를 관리하면서 느낀 점은, 폴더 구조를 잘 잡아두면 나중에 아무리 많은 문서를 작성해도 쉽게 찾을 수 있다는 거야. 이름도 규칙적으로 정리해 두면 훨씬 편리해져. 그리고 버전 관리가 필요하다면 Git과 함께 사용하면 좋겠어. Markdown 파일은 텍스트 파일이라 버전 관리하기 정말 쉬워.

마무리

이렇게 VSCode에서 Markdown 문서를 작성하고 관리하는 방법에 대해 알아봤어. Markdown은 정말 간편하고 유용한 도구라서, 한번 써보면 계속하게 될 거야. 궁금한 점은 댓글로 남겨 주면 좋겠어! Markdown 문서부터 시작해 보면 좋겠어.
