# Node.js 오류 해결을 위한 체크리스트: 가장 흔한 문제와 해결법

Node.js를 사용하다 보면, 가끔은 뜻밖의 오류에 부딪히게 되잖아. "왜 이게 안 돌아가지?" 하면서 머리를 쥐어뜯고, 검색해도 해결책이 잘 안 나올 때가 많지. 그래서 내가 자주 겪었던 오류와 그 해결법을 정리해 봤어. 이 글을 통해 좀 더 수월하게 문제를 해결할 수 있을 거라고 생각해!

## 1. 패키지 설치 오류

### npm install 하면 에러가 발생해!

가장 흔한 오류 중 하나가 바로 `npm install` 할 때 생기는 오류야. 보통 라이브러리나 패키지가 제대로 설치되지 않거나, 버전이 맞지 않아서 생기는 문제인데, 이런 경우엔 다음을 체크해 보자.

- **node_modules 폴더 삭제**: 가끔 남아 있는 캐시나 불필요한 파일 때문에 오류가 발생해. 그래서 `node_modules` 폴더를 통째로 지우고 다시 설치해 보면 해결되는 경우가 많아.
- **npm 캐시 정리**: `npm cache clean --force` 명령어로 캐시를 정리해 보는 것도 좋은 방법이야. 내가 이 방법을 써봤는데, 꽤 유용하더라.

개인적으로는 이 두 가지 방법으로 거의 대부분의 설치 오류를 해결할 수 있었어!

## 2. 포트 충돌 문제

### "포트를 사용할 수 없습니다" 메시지

서버를 실행할 때 "포트를 사용할 수 없습니다"라는 메시지가 뜨면, 다른 프로세스가 그 포트를 사용 중이라는 뜻이야. 이럴 땐 다음을 시도해 보자.

- **사용 중인 포트 확인**: `lsof -i :포트번호` 명령어로 해당 포트를 사용 중인 프로세스를 확인할 수 있어. 그 후, 해당 프로세스를 종료하면 해결돼.
- **포트 변경**: 만약 사용 중인 프로세스를 종료할 수 없다면, 서버의 포트를 다른 번호로 변경하는 것도 좋은 대안이야. 난 이 방법으로 자주 해결하곤 해.

이런 상황에서 스트레스를 많이 받았었는데, 이제는 포트 문제로 걱정할 일이 줄어든 것 같아.

![](https://images.pexels.com/photos/270373/pexels-photo-270373.jpeg)

## 3. 비동기 코드에서의 문제

### "undefined"가 자주 나와!

비동기 코드를 사용할 때, 특히 `async/await`를 쓸 때 "undefined"가 반환되는 경우가 많아. 이건 보통 비동기 함수가 끝나기 전에 값을 사용하려고 할 때 생겨. 이럴 땐 다음을 체크해 보자.

- **await 키워드 사용**: 비동기 함수 앞에 `await`를 붙이지 않으면, 함수가 끝나기 전에 값을 반환하려고 해서 오류가 발생할 수 있어.
- **Promise.all() 사용**: 여러 비동기 작업을 동시에 처리해야 할 때는 `Promise.all()`을 활용하면 좋더라. 이 방법을 사용해 보니 코드가 훨씬 깔끔해지고, 오류도 줄어들었어.

이런 비동기 처리에서의 오류는 정말 골치 아픈데, 나도 처음엔 많이 헤맸어. 그래서 이 부분이 특히 중요하다고 생각해!
