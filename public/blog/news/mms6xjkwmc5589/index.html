Notion과 VSCode 연동하기: 노트와 코드의 완벽한 조화

개발할 때 노트 정리가 너무 중요하다는 거, 다들 공감하지? 코드 작성할 때마다 아이디어가 떠오르기도 하고, 그걸 적어 두지 않으면 잊어버리기 십상이더라. 그래서 나는 Notion과 VSCode를 연동해 보려고 했어. 이렇게 해서 노트와 코드를 한 곳에서 관리할 수 있으면 좋겠다는 생각이 들었거든. 그래서 이걸 정리해 봤어.

1. Notion API 키 발급받기

Notion API 사용 설정하기

먼저, Notion과 VSCode를 연결하기 위해서는 Notion API 키가 필요해. Notion 공식 웹사이트에 가서 API를 활성화해 주면 돼. 내가 처음에 이걸 모르고 삽질한 적이 있는데, 문서에 따라 API 키를 발급받는 게 생각보다 간단하더라.

  1. Notion의 개발자 포털에 들어가.
  2. 새 통합을 만들어서 필요한 권한을 설정해.
  3. API 키를 복사해 두면 돼.

이렇게 해 보니, 나도 모르게 두근거렸어. 뭔가 새로운 기능을 배우는 기분이랄까?

권한 설정

API 키를 발급받고 나면, 이 키를 사용할 페이지에 접근할 수 있도록 권한을 설정해 줘야 해. 내가 해 보니 이 부분이 중요했어. 권한을 제대로 설정하지 않으면 VSCode에서 데이터를 불러올 수가 없거든.

2. VSCode에서 Notion 연동하기

VSCode 확장 설치하기

다음 단계는 VSCode에서 Notion과 연결할 수 있는 확장을 설치하는 거야. "Notion"을 검색해서 관련된 확장을 찾아보면 돼. 내가 사용한 확장은 "Notion for VS Code"라는 것이었어. 설치가 간편하더라.

설정 파일 수정하기

확장을 설치한 후에는 설정 파일을 수정해 줘야 해. settings.json 파일을 열고, 아까 복사한 API 키를 여기에 붙여넣으면 돼. 이 과정을 거치고 나니, 시나리오가 점점 현실로 다가오는 느낌이었어.

{
    "notion.apiKey": "YOUR_API_KEY",
    "notion.databaseId": "YOUR_DATABASE_ID"
}

여기서 YOUR_API_KEY와 YOUR_DATABASE_ID는 각각의 정보를 입력해 주면 돼. 이렇게 해 보니, 내가 원하는 내용을 VSCode에서 손쉽게 불러올 수 있었다는 사실이 너무 좋았어.

3. 코드 작성과 노트 정리의 조화

코드와 노트의 통합 관리

이제 노트와 코드를 연동했으니, 실제로 어떻게 활용할 수 있을까? 내가 해 보니, 코드를 작성하면서 필요한 내용을 바로 Notion에 기록할 수 있어서 정말 편리했어. 예를 들어, 함수에 대한 설명이나 사용 예제를 직접 노트에 남길 수 있더라.

프로젝트 관리의 효율성

특히 프로젝트를 관리할 때 이 조합이 빛을 발하더라. 코드 작성 도중에 필요한 자료나 링크를 Notion에 정리해 두고, VSCode에서 쉽게 불러와서 참고할 수 있었거든. 이렇게 해 보니, 프로젝트 진행이 훨씬 더 매끄러워졌어.

마무리

Notion과 VSCode의 연동은 정말 유용한 도구가 될 수 있어. 노트와 코드를 함께 관리할 수 있으니 생산성이 확실히 높아졌다는 걸 느꼈어. 궁금한 점은 댓글로 남겨 주세요. 이거부터 해 보면 좋겠어!
