VSCode 단축키 마스터하기: 커서 조작으로 작업 속도 향상

코딩할 때마다 마우스를 계속 클릭하느라 힘들다고 느껴본 적 있어? 나도 그랬어. 특히 VSCode를 사용할 때, 키보드로만 작업할 수 있다면 훨씬 더 빠르고 효율적으로 코드를 작성할 수 있을 거 같더라고. 그래서 이번에 VSCode의 커서 조작 단축키를 정리해 봤어. 이걸 알면 작업 속도가 확실히 향상될 거야!

기본 커서 조작 단축키

커서 이동

가장 기본적인 커서 이동부터 보자. 방향키로도 이동할 수 있지만, 몇 가지 단축키를 사용하면 훨씬 더 편리해. 예를 들어, Ctrl + 방향키를 사용하면 단어 단위로 이동할 수 있어. 이거 해 보니 너무 좋더라! 내가 자주 사용하는 단어를 빠르게 수정할 때, 시간 절약이 확실히 되더라고.

줄 단위 이동

그 외에도 Home과 End 키를 사용하면 각각 줄의 시작과 끝으로 빠르게 이동할 수 있어. 이런 간단한 단축키들이 작업 흐름을 끊지 않게 해 주는 느낌이었어. 특히 긴 코드에서 특정 위치로 빨리 가야 할 때 유용해.

선택 영역 조작

텍스트 선택

텍스트를 선택할 때도 단축키가 유용해. Shift + 방향키로 한 글자씩 선택할 수 있고, Shift + Ctrl + 방향키를 누르면 단어 단위로 선택할 수 있어. 예전에 이걸 모르고 마우스로 선택하느라 시간 낭비했는데, 이제는 빠르게 선택하고 수정하는 게 가능해졌어. 이렇게 하니까 실수로 마우스를 잘못 클릭할 일도 줄어들고, 집중력도 더 좋아진 것 같아.

줄 선택

또한, Shift + Alt + 방향키를 사용하면 줄 단위로 선택할 수 있어. 여러 줄을 동시에 수정할 일이 많아서 이걸 자주 쓰는데, 정말 편리하더라. 여러 줄을 한 번에 수정할 수 있으니까, 코드 정리가 한결 편해졌어.

멀티 커서 사용

멀티 선택

VSCode에서 멀티 커서를 활용하는 것도 추천해. Alt + 클릭으로 원하는 위치에 여러 커서를 추가할 수 있어. 이 기능을 처음 사용해 봤을 때, 정말 신세계였어! 여러 곳에서 동시에 같은 코드를 수정할 수 있어서, 코드의 일관성을 유지하는 데 큰 도움이 되더라.

단축키 활용

또한, Ctrl + Alt + 방향키를 사용하면 커서를 위아래로 추가할 수 있어. 이걸 알았을 때는 '왜 이제야 알았지?' 하는 생각이 들었어. 여러 줄에서 동시에 같은 작업을 할 수 있으니, 시간을 절약하는 데 큰 도움이 되었거든.

마무리

이렇게 VSCode의 커서 조작 단축키를 활용해 보니, 작업 속도가 확실히 빨라졌어. 단축키를 잘 활용하면 코딩에 대한 부담도 줄어드는 것 같아. 궁금한 점은 댓글로 남겨 주면 좋겠어. 앞으로도 이런 유용한 팁들을 공유할게! 이번 주에는 이 단축키들을 한번 써 보길 추천해. 이거부터 해 보면 좋겠어!
