Notion에서 VSCode처럼 코드 블록 사용하기: 팁과 트릭

코드 작업을 할 때, Notion과 VSCode의 조합이 얼마나 유용한지 아시나요? 특히 Notion에서 코드 블록을 사용하면 프로젝트 관리와 문서화를 동시에 할 수 있어서 정말 편리하더라고. 그런데 Notion에서 코드 블록을 제대로 활용하는 게 생각보다 쉽지 않아서 고민했었어. 그래서 이걸 정리해 봤어. 어떻게 하면 Notion에서도 VSCode처럼 편리하게 코드 블록을 사용할 수 있는지, 몇 가지 팁과 트릭을 나눌게!

##1. 코드 블록 만들기

코드 블록 추가하는 법

Notion에서 코드 블록을 만드는 건 생각보다 간단해. 그냥 새로운 블록을 만들고, “/code”를 입력하면 코드 블록 옵션이 뜨거든. 이걸 선택하면 코드 입력을 시작할 수 있어.

내가 해 보니, 이런 방식으로 하면 VSCode에서 코드를 작성하는 느낌이 좀 나더라. 물론 VSCode처럼 완벽하진 않지만, 기본적인 문서화에는 정말 유용해. 코드 블록 안에서 언어를 설정할 수 있는데, Python, JavaScript 등 다양한 언어를 지원하니까, 내가 사용하는 언어에 맞게 설정하면 돼.

언어 선택의 중요성

이 부분이 중요했어. 내가 처음에 언어를 선택하지 않고 코드를 넣었더니, 그냥 텍스트처럼 보이더라고. 그래서 이왕이면 언어를 지정해주면 문법 강조도 되고, 가독성도 높아져서 훨씬 보기 좋더라. 사용하고 있는 언어에 맞게 선택해 보는 걸 추천해!

2. 코드 블록 내에서 편집하기

편집의 자유

Notion의 코드 블록은 VSCode처럼 다양한 편집 기능을 제공하지는 않지만, 기본적인 편집은 가능해. 코드를 입력하고 나서 오류가 있으면 쉽게 수정할 수 있어서 좋았어. 내가 여러 번 코드를 수정해 봤는데, 이렇게 해 보니 실시간으로 수정할 수 있어서 정말 편리하더라.

여기서 팁 하나! 코드 블록을 선택한 후, 상단 메뉴에서 ‘Copy’ 버튼을 누르면 코드 전체를 쉽게 복사할 수 있어. VSCode에서 하던 대로 복사해도 되지만, 이렇게 하면 조금 더 편리하게 작업할 수 있을 거야.

3. 협업 시 유용한 기능

팀원과의 공유

Notion은 팀원과 협업할 때 정말 유용한 툴이야. 코드 블록을 작성한 후, 팀원과 공유하면 코드 리뷰를 쉽게 할 수 있어. 내가 예전에 팀 프로젝트를 할 때, Notion에서 코드 블록을 활용해서 서로의 코드를 검토했는데, 댓글 기능을 통해 피드백을 주고받는 게 굉장히 효율적이었어.

팀원들과 함께 작업할 때는 코드 블록을 활용해서 서로의 코드를 명확하게 공유하는 게 중요해. 특히 코드에 대한 설명이나 메모를 추가할 수 있어서, 나중에 다시 봐도 이해하기 쉬워. 이런 점이 협업에 큰 도움이 되더라.

4. 코드 블록을 통한 문서화 전략

문서화의 중요성

Notion의 코드 블록을 활용하면 코드뿐만 아니라 관련 문서화도 함께 할 수 있어. 내가 프로젝트를 진행하면서 코드와 함께 문서를 정리했더니, 나중에 다시 돌아보기도 쉽고, 프로젝트 이해도가 높아지더라고.

여기서 중요한 점은, 코드 블록 아래에 설명을 추가하는 거야. 이렇게 하면 나중에 다른 사람이나 나 자신이 봐도 이해하기 쉬운 문서가 완성돼. 개인적으로 이런 문서화 방식이 정말 좋았어.

마무리

Notion에서 VSCode처럼 코드 블록을 사용하는 방법을 알아봤어. 코드 블록을 활용하면 문서화와 협업이 훨씬 수월해지니까, 꼭 한 번 시도해 보길 바래! 궁금한 점은 댓글로 남겨 주세요. 이거부터 해 보면 좋겠어!
