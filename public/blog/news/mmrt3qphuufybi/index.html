npm install 중 발생하는 일반적인 오류와 해결 방법

프로그램 개발하면서 npm install 할 때, 여러 가지 오류에 부딪히곤 하지? 뭘 잘못했는지 도대체 모르겠고, 인터넷에서 찾아보면 뚱딴지 같은 해결책만 나오고… 정말 답답하더라. 그래서 내가 겪었던 일반적인 오류와 그 해결 방법을 정리해 봤어. 이 글을 읽고 나면, 조금이라도 도움이 될 거라고 생각해!

1. ERR! code E404 오류

이게 뭔가요?

이 오류는 npm에서 의존성을 찾지 못할 때 발생해. 예를 들어, 패키지가 레지스트리에 없거나 잘못된 경로를 입력했을 때 생기지. 나도 처음에 이 오류를 보고 정말 당황했어. "이 패키지가 없다니, 대체 뭘 잘못한 거지?"라는 생각이 절로 들더라.

해결 방법

이럴 땐 아래와 같은 방법을 시도해보면 좋겠어:

  • 패키지 이름을 다시 확인해 보자. 오타가 있을 수 있어.
  • npm 레지스트리를 변경해 보자. 공식 레지스트리 외에 다른 것을 사용하고 있다면, 다시 원래대로 돌려놓는 것도 방법이야.

내가 이 방법을 써봤더니, 의존성이 제대로 설치되더라고. 그래서 항상 패키지 이름을 두 번 확인하는 습관이 생겼어!

2. ERR! code EACCES 오류

왜 이럴까?

이 오류는 권한 문제로 발생해. 보통 npm을 설치할 때 admin 권한이 없어서 생기더라. 나는 처음에 이 오류를 보고 "내가 뭘 잘못했지?" 하고 고민했어. 이럴 땐 조금만 더 신경 쓰면 돼.

해결 방법

이 오류를 해결하려면 아래 방법을 시도해봐:

  • npm 명령어 앞에 sudo를 붙여서 실행해. (단, 이 방법은 macOS/Linux에서만 가능해)
  • 또는 npm을 로컬 사용자 디렉토리에 설치하도록 설정해 보자. 이걸 위해선 npm config set prefix ~/.npm-global 명령어를 사용해.

내가 sudo를 사용해봤더니, 바로 해결됐어. 하지만 권한 문제는 항상 조심해야 해. 잘못하면 다른 파일에까지 영향을 줄 수 있으니까!

3. npm ERR! missing script: start 오류

이게 왜 발생했지?

이 오류는 보통 package.json 파일에 start 스크립트가 없을 때 발생해. 처음에 내가 이 오류를 만났을 때는 "이런 게 있나?" 하고 많이 당황했어. 그냥 npm start를 입력했는데, 이런 메시지가 나와서 멘붕이더라.

해결 방법

이 오류는 간단하게 해결할 수 있어:

  • package.json 파일을 열어보자. scripts 섹션에 "start": "node app.js" 같은 코드를 추가해 주면 돼. 여기에 app.js는 너의 메인 파일이야.

이 방법을 해봤더니, 스크립트가 잘 실행되더라. 그래서 이제는 항상 내가 필요한 스크립트가 있는지 확인하고 시작해.

마무리

npm install 중에 발생하는 오류는 정말 다양하지만, 대부분의 경우 해결방법이 간단해. 이 글에서 언급한 오류들을 참고해서 문제를 해결해 보길 바라. 궁금한 점은 댓글로 남겨 주세요! 다음 번엔 npm의 다른 유용한 팁을 다뤄볼게.
