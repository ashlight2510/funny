VSCode에서 커서 단축키 활용하기: 생산성 2배 높이기

코딩할 때 커서를 자주 이동해야 해서 불편한 적, 다들 한 번쯤 있으실 거예요. 특히 긴 파일을 다룰 때는 커서를 한 줄씩 이동시키는 게 너무 귀찮더라고요. 그래서 이걸 정리해 봤어! VSCode에서 커서 단축키를 활용해 생산성을 높이는 방법을 공유해볼게.

1. 기본 커서 이동 단축키

먼저, 기본적인 커서 이동 단축키부터 알아보자. 이건 정말 필수야.

  • 위아래 이동: ↑, ↓
  • 좌우 이동: ←, →
  • 단어 단위로 이동: Ctrl + ←, Ctrl + →
  • 줄의 시작과 끝으로 이동: Home, End

이렇게 기본 단축키를 활용하면 코드에서 빠르게 위치를 변경할 수 있어. 내가 써 보니, 특히 단어 단위로 이동할 때 정말 유용하더라. 코드 작성할 때 오타를 수정할 때도 훨씬 빠르게 작업할 수 있었어.

2. 여러 줄 선택하기

이제 좀 더 고급 단축키인 여러 줄 선택하기를 알아보자. 코드 블록을 선택할 때는 아래와 같은 단축키를 쓰면 편해.

  • 여러 줄 선택: Shift + ↑, ↓
  • 블록 선택: Alt + Shift + 드래그

이 기능은 특히 코드 리팩토링을 할 때 유용해! 내가 한 번 여러 줄을 동시에 바꿔야 할 때 이걸 사용해 봤더니 시간을 진짜 많이 절약했어. 마우스로 드래그하면서 선택하는 것보다 훨씬 효율적이더라.

3. 커서 복사 및 붙여넣기

커서를 여러 위치에 동시에 놓고 작업할 수 있는 기능도 있어. 이걸 활용하면 정말 시간 절약이 가능해.

  • 커서 추가: Ctrl + Alt + ↓ (또는 ↑)

이 단축키를 사용하면 원하는 위치에 여러 커서를 추가할 수 있어. 예를 들어, 특정 변수를 여러 곳에서 수정해야 할 때 이 기능을 쓰면, 한 번에 수정할 수 있더라. 처음에 이 기능을 알고 나서는, 정말 신세계였어.

4. 커서 위치 기억하기

마지막으로, 커서 위치를 기억하는 기능도 알아두면 좋아.

  • 이전 위치로 이동: Ctrl + -
  • 다음 위치로 이동: Ctrl + Shift + -

이 기능은 긴 코드 파일에서 작업할 때 정말 유용해. 내가 작업하던 곳으로 빠르게 돌아갈 수 있어서, 작업 효율이 확실히 높아지더라. 특히 긴 디버깅을 할 때는 이 기능 없인 힘들었을 거야.

마무리

이렇게 VSCode에서 커서 단축키를 활용하는 방법을 알아봤어. 간단한 단축키만으로도 작업 속도가 확실히 빨라질 수 있으니, 한 번 해 보길 추천해! 궁금한 점은 댓글로 남겨 주세요. 이거부터 해 보면 좋겠어!
