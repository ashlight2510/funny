코드 스니펫을 정리하려고 하는데, 어떤 툴을 써야 할지 막막했던 적이 있지? 여러 가지 방법을 시도해 봤지만, 결국에는 Obsidian이 가장 편리하더라. 그래서 오늘은 Obsidian을 활용해서 코드 스니펫을 정리하는 방법에 대해 정리해 볼게.

Obsidian이 뭐야?

개인적인 경험

먼저, Obsidian이 뭔지 간단히 이야기해볼게. Obsidian은 마크다운 기반의 노트 작성 툴인데, 개인적으로는 다양한 링크와 태그 기능 덕분에 정말 좋아. 처음에 이걸 써보려고 했을 때, 단순한 노트 앱이 아닐 거라는 느낌이 확 들었어. 예를 들어, 내가 작성한 코드 스니펫을 주제별로 정리하면서 관련된 정보들을 링크로 연결할 수 있으니까, 나중에 찾기도 쉬워. 그래서 코드 스니펫을 정리할 때도 굉장히 유용하더라.

## 태그와 링크 활용하기

### 관련 정보 연결하기

코드 스니펫을 정리하면서 태그와 링크를 활용하는 것도 잊지 마. 예를 들어, 자주 사용하는 함수나 라이브러리 이름을 태그로 추가해 두면, 나중에 관련된 코드나 노트를 쉽게 찾을 수 있어. 내가 해 봤는데, 이렇게 해 두니까 필요한 정보를 한눈에 볼 수 있어서 너무 좋았어.

링크를 걸어 두는 것도 추천해. 예를 들어, 특정 코드 스니펫이 어떤 프로젝트에서 사용되는지를 링크로 연결해 놓으면, 나중에 해당 프로젝트를 다시 작업할 때 큰 도움이 돼. 이 점이 Obsidian의 매력이 아닐까 싶어.
