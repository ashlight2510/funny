VSCode 키보드 단축키로 개발 효율 극대화하기

코딩을 하다 보면, 매번 마우스를 들고 클릭하고 드래그하는 게 너무 귀찮고 비효율적이라는 생각이 들 때가 많지? 나도 그랬어. 그래서 VSCode에서 제공하는 다양한 키보드 단축키를 활용하기 시작했는데, 이게 정말 개발 효율을 높이는 데 큰 도움이 되더라. 그래서 오늘은 VSCode의 유용한 키보드 단축키를 정리해 봤어.

1. 기본 키보드 단축키

VSCode의 기본 키보드 단축키는 정말 간단하고 직관적이야. 예를 들어, Ctrl + P를 누르면 파일을 빠르게 열 수 있어. 처음에 이걸 알았을 때, "아, 이렇게 간단하게 파일을 찾을 수 있구나!" 하고 감탄했어.

또한, Ctrl + Shift + P를 누르면 명령 팔레트를 열 수 있는데, 여기서 원하는 명령어를 검색해서 실행할 수 있어. 이런 기능 덕분에 매번 메뉴를 찾아다니지 않아도 되고, 개발에만 집중할 수 있게 돼. 개인적으로는 이 단축키가 제일 유용하더라.

2. 코드 편집을 위한 단축키

코드를 작성할 때, 자주 사용하는 단축키가 몇 가지 있어. 예를 들어, Ctrl + /를 누르면 선택한 코드 주석 처리 또는 주석 해제가 가능해. 주석을 자주 사용하다 보니 이 단축키가 없었으면 진짜 힘들었을 거야.

또한, Alt + ↑/↓로 코드의 줄을 위아래로 이동할 수 있어. 이걸로 코드를 재배치하는 게 정말 간편해지는데, 처음에 이 기능을 발견했을 때 "왜 이렇게 편리한 걸 이제야 알았지?" 하고 혼자서 놀랐어.

3. 디버깅을 위한 단축키

개발하다 보면 디버깅이 정말 중요하지. F5를 누르면 디버깅을 시작할 수 있고, F9로는 브레이크 포인트를 추가할 수 있어. 이 두 가지 단축키는 나에게 디버깅 시간을 많이 줄여줬어.

처음에는 마우스로 클릭하면서 디버깅했었는데, 이제는 키보드로 훨씬 빠르게 문제를 찾고 해결할 수 있게 됐어. 그래서 디버깅할 때는 이 단축키들만큼은 꼭 기억해 두면 좋겠어.

4. 멀티 커서 활용하기

VSCode에서 멀티 커서를 사용하는 것도 정말 유용해. Ctrl + Alt + ↓ 또는 Ctrl + Alt + ↑를 사용하면 여러 줄에 동시에 커서를 추가할 수 있어. 이걸로 한 번에 여러 위치에서 코드를 수정할 수 있어서 정말 시간을 절약할 수 있어.

처음 이 기능을 써 봤을 때, "이게 진짜 가능해?" 하고 놀랐어. 나처럼 똑같은 작업을 여러 번 해야 하는 경우라면 이 기능을 꼭 활용해 보라고 추천할게.

마무리

VSCode의 키보드 단축키를 활용하면 개발 효율을 확실히 극대화할 수 있어. 이 글에서 소개한 단축키들을 활용해 보면, 개발이 한층 더 수월해질 거야. 궁금한 점은 댓글로 남겨 주면 좋겠고, 일단 이 단축키들부터 해 보길 추천해!
