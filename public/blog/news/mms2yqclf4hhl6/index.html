GitHub 협업을 위한 VSCode의 필수 확장 프로그램 5선

프로그래밍을 하다 보면 혼자 작업하는 것보다 팀원들과 협업하는 경우가 더 많잖아? 그럴 때 GitHub을 쓰는 건 필수인데, 여러 명이 동시에 작업하다 보면 코드 충돌이나 버전 관리가 정말 골치 아프더라구. 그래서 이걸 조금 더 수월하게 도와줄 VSCode의 유용한 확장 프로그램들을 정리해 봤어. 나도 써 보면서 많이 도움을 받았거든!

1. GitLens

코드의 배경을 이해하게 해주는 마법

GitLens는 내 코드의 변경 이력이나 작성자를 쉽게 알 수 있게 해주는 확장 프로그램이야. 팀원들이 작성한 코드의 의도를 파악하는 데 큰 도움이 되더라구. 예를 들어, 누가 언제 어떤 이유로 코드를 수정했는지를 한눈에 볼 수 있어.

내가 처음에 이걸 사용해 봤을 때, "아, 이 부분은 왜 이렇게 수정됐지?"라는 의문이 생겼는데, GitLens 덕분에 그 의문이 쉽게 해결됐어. 코드 리뷰할 때도 유용하게 썼고, 팀원들과의 커뮤니케이션이 한층 더 원활해진 느낌이었어.

2. Live Share

실시간으로 함께 코딩하기

Live Share는 팀원들과 실시간으로 코드를 공유하면서 함께 작업할 수 있는 기능이야. 예를 들어, 누군가의 코드를 바로 수정해 주거나, 설명을 덧붙이면서 작업할 수 있어. 처음 이걸 사용해 봤을 때, 마치 화상 회의처럼 서로의 화면을 보면서 대화하는 게 신기하고 재밌더라구!

이렇게 해 보니, 서로의 생각을 즉각적으로 나누면서 문제를 해결하는 데 큰 도움이 됐어. 특히 원격 근무가 많아진 요즘엔 필수적인 툴 같아.

3. Prettier

코드 스타일을 통일하는 비결

팀원들이 각자 다른 코드 스타일로 작업하면 코드가 지저분해지기 마련이야. 이럴 때 Prettier라는 확장 프로그램이 큰 역할을 해. 코드의 형식을 자동으로 정리해 주거든.

내가 코드를 작성하면서 Prettier를 사용해 보니, 코드가 깔끔하게 정리되는 걸 보면서 뿌듯함을 느꼈어. 팀원들 간의 코드 스타일을 통일하는 데도 큰 도움이 됐고, 나중에 코드 리뷰할 때의 수고도 덜어주더라구.

4. ESLint

코드 오류를 사전에 잡아주는 수호자

ESLint는 자바스크립트 코드에서 오류를 미리 잡아주는 역할을 해. 코드 작성 중에 발생할 수 있는 실수를 사전에 경고해 주니까, 버그를 줄일 수 있어. 나도 처음에 이걸 도입해 봤을 때, 여러 번의 실수를 줄일 수 있었던 경험이 있어.

팀원들도 ESLint를 사용하고 나선 코드 품질이 한층 향상됐다는 피드백을 주더라구. 코드 리뷰를 하면서 "이 부분은 ESLint가 잡아줬어!"라는 대화가 오가는 게 정말 뿌듯했어.

마무리

GitHub 협업을 위한 VSCode의 필수 확장 프로그램들을 살펴봤어. GitLens, Live Share, Prettier, ESLint 모두 팀워크를 높이고 코드 품질을 향상시키는 데 큰 도움이 되더라구. 이 확장 프로그램들 덕분에 협업하는 재미도 느끼고, 코드 작성도 한층 수월해졌어.
