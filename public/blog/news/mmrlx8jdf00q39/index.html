VSCode의 커서 단축키로 생산성 높이는 비법

프로그래밍할 때 커서 이동이 느리면 답답한 경험, 한 번쯤 해봤지? 뭘 하려는지 모르겠고, 코드 한 줄을 편집하는 데도 시간이 걸리면 진짜 짜증나더라. 그래서 VSCode에서 커서 단축키를 활용하면 생산성을 높일 수 있다는 걸 정리해 봤어. 이 글을 읽고 나면, 더 빠르고 효율적으로 코딩할 수 있을 거야!

커서 이동 단축키: 기본부터 마스터하기

기본 이동 단축키

먼저, 커서를 빠르게 이동시키는 기본 단축키에 대해 알아보자. 화살표 키는 물론이고, Ctrl + 화살표를 이용하면 단어 단위로 이동할 수 있어. 이렇게 해 보니 훨씬 빠르게 코드를 읽고 수정할 수 있더라.

또한, Home과 End키로 줄의 시작과 끝으로 빠르게 이동할 수 있는 것도 유용해. 이 단축키들을 잘 활용하면, 코드 전체를 훑어보는 데 큰 도움이 돼. 개인적으로는 Ctrl + 화살표가 정말 좋았어. 단어 단위로 이동하니까 코드의 흐름을 더 쉽게 파악할 수 있더라고.

선택 영역 확장하기

여러 줄 선택하기

다음은 선택 영역을 확장하는 단축키야. Shift + 화살표로 선택 영역을 늘릴 수 있는데, 이걸 응용하면 여러 줄을 동시에 선택할 수 있어. 예를 들어, Shift + Alt + 화살표 아래를 누르면 아래쪽으로 여러 줄을 동시에 선택할 수 있지. 이 기능 덕분에 여러 줄을 한 번에 수정할 수 있어서 작업 효율이 확 올라갔어.

내가 어떤 프로젝트에서 여러 줄의 주석을 달아야 했는데, 이 단축키를 사용해 보니 훨씬 수월하게 작업할 수 있었어. 뭘 선택해야 할지 고민될 때는 이 방법이 정말 유용해!

커서 복사와 붙여넣기

커서 복사하기

커서를 복사하는 것도 생산성을 높이는 중요한 팁이야. Alt + Shift + 드래그로 커서를 여러 개 생성할 수 있는데, 이걸 활용하면 동시에 여러 줄에서 작업할 수 있어. 예를 들어, 변수명을 변경해야 할 때, 여러 줄에서 동시에 수정할 수 있으니 시간을 절약할 수 있더라.

내가 이 기능을 처음 써봤을 때는 완전 신세계였어. 여러 부분을 동시에 수정하니 시간이 정말 절약되더라고. 그래서 이 단축키는 꼭 기억해 두면 좋을 거 같아!

다중 커서 활용하기

다중 커서로 한 번에 수정하기

마지막으로, 다중 커서를 활용해 보자. Ctrl + Alt + 화살표를 이용하면 위아래로 커서를 추가할 수 있어. 이걸 활용하면 한 번에 여러 곳을 수정할 수 있으니까, 정말 편리해. 특히 같은 함수 이름이 여러 곳에 있을 때, 이 방법으로 한 번에 수정하면 시간 절약이 확실해.

내가 이 기능을 사용해 보니, 같은 코드를 반복해서 수정하는 일이 줄어들어서 정말 좋았어. 이젠 다중 커서 없이는 작업을 못 하겠더라고!

마무리

이렇게 VSCode의 커서 단축키를 활용하면 생산성을 높일 수 있는 방법을 정리해 봤어. 커서 이동과 선택, 복사, 다중 커서 활용까지, 각각의 단축키를 잘 활용하면 코딩할 때 훨씬 수월해질 거야. 궁금한 점은 댓글로 남겨 주세요! 이거부터 해 보면 좋겠어!
