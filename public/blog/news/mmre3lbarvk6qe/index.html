VSCode의 커서 조작으로 코딩 속도 향상시키기

코딩을 하다 보면 커서를 어떻게 잘 조작할지 고민이 많지? 특히 긴 코드에서 원하는 부분으로 이동할 때마다 마우스를 쓸까, 단축키를 쓸까 고민하게 되더라. 그래서 오늘은 VSCode에서 커서를 조작하는 방법을 정리해 봤어. 이걸 활용하면 코딩 속도가 확실히 빨라질 거야!

커서 이동 단축키 활용하기

기본 단축키 익히기

첫 번째로 알아야 할 것은 커서를 이동하는 기본 단축키야. 예를 들어, ↑, ↓, ←, → 키는 기본적으로 커서를 한 줄씩, 혹은 한 글자씩 이동할 수 있게 해 주지. 하지만 이게 다가 아니야. Ctrl + ↑ 또는 Ctrl + ↓를 누르면 커서를 한 페이지 위아래로 이동할 수 있어. 이걸 사용해 보니, 불필요하게 마우스를 움직일 필요가 없어져서 시간 절약이 확실히 되더라.

여러 줄을 선택하는 방법

이제 여러 줄을 선택하는 방법도 알아보자. Shift 키를 누른 상태에서 방향키를 누르면 여러 줄을 쉽게 선택할 수 있어. 내가 해 보니, 이걸 활용해서 한 번에 여러 줄을 수정할 수 있어서 정말 편했어. 코드를 수정할 때 같은 형식의 내용을 여러 개 바꿔야 할 때 유용했지.

멀티 커서 기능 활용하기

멀티 커서로 동시에 수정하기

그다음으로는 멀티 커서 기능이야. Alt를 누른 채로 클릭하면 여러 곳에 커서를 동시에 둘 수 있어. 이건 정말 혁신적인 기능이더라. 예를 들어, 변수명을 여러 곳에서 한꺼번에 바꾸고 싶을 때, 하나하나 클릭할 필요 없이 한 번에 수정할 수 있었거든. 개인적으로 이 기능 덕분에 코드를 수정하는 시간이 확 줄어들었어.

단축키로 멀티 커서 만들기

또, Ctrl + Alt + ↑ 또는 Ctrl + Alt + ↓를 누르면 현재 커서 위치에서 위아래로 새 커서를 추가할 수 있어. 이걸 해 보니, 반복적인 작업을 할 때 진짜 유용했어. 여러 줄에 같은 내용을 삽입해야 할 때 특히 효과적이었거든. 이 기능을 모르고 살았던 게 아쉬울 정도야!

커서 위치 기억하기

자주 가는 위치에 북마크 추가하기

마지막으로, 커서 위치를 기억하는 방법도 있어. VSCode에서는 특정 위치에 북마크를 추가할 수 있는 확장 기능이 많아. 내가 사용해 본 확장 중 하나는 Bookmarks라는 거야. 이걸 설치하면 자주 가는 코드의 위치를 북마크로 저장해 두고 쉽게 이동할 수 있어. 이 기능이 없었을 때는 매번 스크롤을 내려서 찾느라 힘들었는데, 이제는 클릭 몇 번으로 이동할 수 있으니 정말 편리해.

마무리

이렇게 VSCode에서 커서를 조작하는 여러 가지 방법을 정리해 봤어. 간단한 단축키와 멀티 커서 기능을 활용하면 코딩 속도가 확실히 향상될 거야. 내가 경험해 보니 이 방법들이 정말 유용했어. 궁금한 점은 댓글로 남겨 줘! 이거부터 해 보면 좋겠어!
