Cursor 기능을 이용한 VSCode에서의 빠른 코드 탐색 방법

코드를 작성하다 보면, 어떤 부분을 수정해야 할지 또는 특정 기능이 어디에 있는지 찾아 헤매는 경우가 많지? 나도 처음에는 이게 너무 귀찮고 시간 낭비라고 느꼈어. 그래서 VSCode의 Cursor 기능을 활용해 보니, 생각보다 훨씬 편리하더라. 그래서 오늘은 이 기능을 사용해서 코드를 빠르게 탐색하는 방법을 정리해 봤어!

Cursor 기능이란?

기본 개념 이해하기

Cursor 기능은 간단히 말해서, 코드 내에서 커서를 자유롭게 이동시켜서 특정 부분을 빠르게 수정하거나 탐색할 수 있도록 도와주는 기능이야. 예를 들어, 여러 줄의 코드를 한 번에 선택하거나, 같은 단어를 한꺼번에 수정할 수 있는 기능이지. 이런 기능이 있으면 정말 편해!

내가 느낀 장점

내가 쭉 사용해 보니까, 이 기능이 특히 유용한 순간이 바로 코드 리뷰할 때였어. 리뷰하면서 여러 부분을 동시에 수정해야 할 경우, Cursor 기능을 사용하니까 훨씬 더 빠르게 작업할 수 있었어. 특히, Shift + Alt + 방향키를 이용해서 여러 줄을 선택하는 방법은 정말 추천해! 이 방식으로 코드가 어떻게 구성되어 있는지를 한눈에 파악할 수 있더라.

검색 단축키 활용하기

코드 검색 단축키

VSCode에서는 Ctrl + F를 눌러서 특정 단어를 검색할 수 있는데, 이거 말고도 Ctrl + P를 사용하면 파일을 빠르게 검색할 수 있어. 파일 이름을 아는 경우에는 이 기능이 진짜 유용해.

내가 써 본 팁

처음에 Ctrl + P를 사용할 때는 "파일 이름이 무슨 의미가 있었지?" 하고 고민하던 기억이 나. 하지만 이제는 자주 사용하는 파일 이름은 미리 메모해 두고, 검색할 때마다 그 리스트를 참고해. 이렇게 하니까 코드 탐색이 훨씬 수월해졌어!

여러 커서 사용하기

멀티 커서의 힘

멀티 커서를 사용하면, 동일한 코드 라인을 한 번에 수정할 수 있어서 정말 효율적이야. Alt + 클릭으로 원하는 위치에 커서를 추가할 수 있는데, 이걸 알게 된 후로는 중복된 코드를 수정할 때 큰 도움이 됐어.

개인적인 경험

처음 이 기능을 써봤을 때는 "이런 것도 가능하구나!" 싶었어. 여러 줄의 변수를 한꺼번에 변경할 수 있으니, 매번 수동으로 수정하는 것에 비해 시간 절약하는 게 확실히 느껴졌거든. 만약 이 기능을 안 써 본다면, 꼭 한 번 사용해 보라고 권하고 싶어!

마무리

VSCode의 Cursor 기능은 코드 탐색을 훨씬 더 빠르고 효율적으로 만들어 주는 도구야. 여러 가지 방법을 조합해서 사용해 보면, 정말 많은 시간을 절약할 수 있어. 궁금한 점이 있으면 댓글로 남겨 줄래? 이 기능부터 해 보면 좋겠어!
