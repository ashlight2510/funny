VSCode에서 Cursor를 효과적으로 활용하는 5가지 팁

코드 작성할 때, 커서를 어떻게 다루느냐에 따라 생산성이 확 달라지더라. 내가 처음 VSCode를 시작했을 때, 커서를 그냥 왔다 갔다 하면서 코드를 작성했던 기억이 있어. 그때는 뭘 어떻게 해야 할지 막막했는데, 지금은 몇 가지 팁 덕분에 훨씬 편하게 작업하고 있어. 그래서 오늘은 VSCode에서 커서를 효과적으로 활용하는 방법을 정리해봤어.

1. 멀티 커서 사용하기

멀티 커서의 매력

멀티 커서는 여러 곳에서 동시에 코드를 수정할 수 있게 해줘. 예를 들어, 같은 변수명을 여러 군데서 바꿔야 할 때 정말 유용해. 그냥 Alt 키를 누르면서 원하는 위치를 클릭하면 여러 개의 커서를 만들 수 있어.

내가 해 본 경험

처음에 멀티 커서를 사용할 때는 너무 신기해서 마구잡이로 클릭했던 기억이 나. 그런데 나중에 보니까, 너무 많은 위치에 커서를 두면 오히려 헷갈리더라. 그래서 적당히 사용하는 게 중요하다는 걸 느꼈어. 이렇게 해 보니 작업 속도가 확 올라갔어!

2. 커서 이동 단축키 익히기

단축키로 커서 이동하기

VSCode에서는 커서를 빠르게 이동할 수 있는 다양한 단축키가 있어. Ctrl + 방향키를 누르면 단어 단위로 이동할 수 있고, Home이나 End 키를 누르면 줄의 시작과 끝으로 빠르게 이동할 수 있어.

내 경험담

처음에는 마우스를 자주 사용했는데, 단축키를 익히니 정말 편해졌어. 특히 Ctrl + 방향키는 코드의 흐름을 빠르게 확인하는 데 큰 도움이 됐어. 이걸 알았으면 좀 더 빨리 효율적으로 작업할 수 있었을 텐데, 좀 늦게 발견했어.

3. 커서 복제 및 삭제

커서 복제와 삭제의 중요성

커서를 복제(Ctrl + D)하거나 삭제(Ctrl + U)하는 기능도 자주 사용하게 돼. 이걸 이용하면 불필요한 커서를 쉽게 정리할 수 있어.

경험에서 온 팁

이 기능을 처음 알았을 때는 정말 편리하더라. 특히 여러 줄에 같은 코드를 붙여넣어야 할 때 유용했어. 하지만 처음 사용해보면 커서가 너무 많아져서 헷갈릴 수 있으니 조심해야 해. 내가 그랬거든!

4. 커서 위치 기억하기

커서 위치 기억하기

코드 작성 중에 자주 돌아가야 하는 위치가 있잖아. 이럴 때는 Ctrl + -로 이전 위치로 돌아가고, Ctrl + Shift + -로 다음 위치로 갈 수 있어.

내 경험

이 기능을 모르고 작업하다가 참 불편했어. 그런데 이걸 알게 된 이후로는 코드의 특정 위치를 쉽게 기억하고 이동할 수 있어서 작업이 훨씬 수월해졌어. 아주 유용하니 한 번 써봐!

마무리

이렇게 VSCode에서 커서를 효과적으로 활용하는 방법 몇 가지를 소개했어. 커서의 기능을 잘 활용하면 정말 많은 시간을 절약할 수 있을 거야. 궁금한 점은 댓글로 남겨 주세요! 이번 주에는 이 팁들 중 하나부터 해 보면 좋겠어.
