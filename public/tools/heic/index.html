HEIC → JPG 변환기 (WebP/PNG 변환 · 압축 · 리사이즈 · ZIP)

업로드 없이 브라우저에서 바로 변환돼. 여러 장 넣고 한 번에 ZIP으로 받을 수도 있어.

드래그&드롭 또는 파일 선택 HEIC / JPG / PNG / WebP 지원 (여러 장 가능)
· HEIC 변환은 기기/브라우저에 따라 처리 시간이 조금 걸릴 수 있어.
· 변환은 로컬에서만 진행돼(서버 업로드 없음).
JPG/WebP에 적용(높을수록 품질↑ 용량↑). PNG는 무시됨.
0이면 원본 유지. 예: 1600 입력 시 긴 변이 1600px로 축소.
✔ 변환 규칙
- HEIC/HEIF: heic2any로 디코딩 후 캔버스로 재인코딩
- JPG/PNG/WebP: 캔버스로 출력 포맷에 맞게 재인코딩

✔ 추천 세팅
- HEIC → JPG: 품질 85 / 리사이즈 0
- 용량 줄이기: WebP + 품질 75 + 리사이즈 1600
· 아이폰 사진(HEIC) 여러 장 넣고 “변환 시작” → “ZIP 다운로드”로 끝.
· PC에서 웹용으로 최적화: WebP + 리사이즈 1600 + 품질 75 추천.
